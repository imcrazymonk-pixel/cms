# CONTRIBUTING — HexaVeil CMS

## Git — соглашение о сообщениях коммитов

**Главное правило: сообщение коммита описывает то, ЧТО РЕАЛЬНО СДЕЛАНО
(поведение, результат, затронутые модули) — простым понятным языком,
а не кодовое обозначение задачи, номер тикета или абстрактное «update».**

Формат — **Conventional Commits**:

```
<тип>(<область>): <что сделано понятным языком>

<необязательное тело: список ключевых изменений>
```

### Типы

| Тип | Когда используется |
|-----|--------------------|
| `feat` | новая функциональность |
| `fix` | исправление бага/ошибки |
| `refactor` | изменение кода без смены поведения |
| `style` | оформление (CSS, шрифты, форматирование) |
| `docs` | документация |
| `chore` | рутина (сборка, зависимости, конфиги) |
| `perf` | производительность |
| `test` | тесты |

### Область (scope)

Коротко и по делу: `dashboard`, `sidebar`, `settings`, `finance`, `posts`,
`compose`, `docs`, `admin`, `theme`, …

### Правила описания

1. **Описывай результат, а не внутренний идентификатор.**
   - ❌ `fix: задача 42`
   - ❌ `feat: update code`
   - ❌ `chore: changes`
   - ✅ `feat(dashboard): меню «Настроить» — скрытие и порядок виджетов`
   - ✅ `fix(compose): healthcheck через 127.0.0.1 вместо localhost`
2. Пиши в императиве, понятным языком (что сделано, а не «что-то сделано»).
3. Если изменений много — добавь тело коммита со списком по пунктам.
4. Язык — русский (как принято в проекте), названия технологий — как есть.
5. Один коммит = одна логическая задача. Не смешивай несвязанные правки.

### Примеры (из истории репозитория)

- `feat(finance): in-app auto-sync scheduler for Platega/YooKassa`
- `fix(compose): web healthcheck uses 127.0.0.1 (localhost resolves to IPv6 ::1, nginx listens IPv4)`
- `feat(settings): SEO tab + theme tab with grouped options; wire site settings to public head`
- `feat(admin): collapsible Параметры/SEO blocks in post editor (collapsed by default)`
- `chore(build): rebuild admin SPA bundle (dist)`

### Чеклист перед коммитом

- [ ] Сообщение описывает реальный результат, а не код/номер задачи
- [ ] Указан тип и область (`type(scope): …`)
- [ ] Нет секретов и ключей в изменениях (`.env`, пароли, токены — не коммитить)
- [ ] Сборка проходит (`web/frontend`: `npm run build`)
- [ ] Закоммичены только нужные файлы
