# Spec: Редизайн админ-панели CMS в стиле remnawave-admin

> Дата: 2026-08-26
> Статус: Approved (решения приняты пользователем)
> Приоритет: Итерация 1 «Красота + Платформа»

## Objective

Перевести админ-панель CMS (`admin/`) с текущей светлой темы на дизайн-систему, визуально идентичную панели **remnawave-admin** (тёмная тема, glass-эффекты, mesh-фон, 6 акцентных тем, светлый режим, таблицы с продвинутыми настройками). Попутно заложить платформенные компоненты ядра: `DataGrid` (единый рендерер таблиц) и систему настроек вида, на которые в будущем встанут модули `fin`, `remnawave`, `bedolaga`.

**Успех =** админка выглядит как remnawave-admin, весь текущий функционал работает 1:1, ни один URL/маршрут/POST-обработчик не изменён.

## Scope

### Входит
- Админ-панель: layout, сайдбар, шапка, дашборд, все CRUD-экраны (посты, категории, страницы, медиа, меню, пользователи, настройки, темы, виджеты)
- Страница входа (`login`)
- Дизайн-система ядра (токены, темы, glass, mesh)
- Компонент `DataGrid` в ядре
- Перевод всех списков на `DataGrid`
- Командная палитра (Ctrl+K)
- Настройки вида: плотность, радиус, размер шрифта, анимации, переключатель тем
- Иконки: замена на Lucide
- Включение новых шрифтов (Montserrat, Unbounded, JetBrains Mono)

### НЕ входит (запрещено трогать)
- **HexaVeil** — лендинг (`public/hexaveil/`, `templates/themes/hexaveil/`, `public/hexaveil/`), ни один файл
- **Блог** — публичные темы `default`, `modern`, `minimal` и `public/css/style.css` (решение 15-A1)
- Логика ядра: `core/routes.php` (маршруты не менять), контроллеры (логика не меняется), модели, БД-запросы
- Имена полей форм (`name="title"` и т.д.) — не менять
- POST-обработчики, CSRF, сессии, права доступа
- Python-проект `Fin/` (отдельно, переделывается в модуль позже)

## Tech Stack

- PHP 7.4+ (без фреймворков), vanilla CSS, vanilla JS
- Никаких npm, node_modules, build steps, CSS-препроцессоров
- Никаких внешних библиотек, кроме: Google Fonts, уже подключённый TinyMCE, Chart.js (не нужен в этой итерации, но не удалять)
- Иконки: inline SVG **Lucide** (stroke-based, 24×24)

## Code Style

**CSS:**
- Все значения цвета/радиуса/шрифта — только через CSS-переменные из `tokens.css`/`themes.css`, никаких хардкод-хексов в компонентах
- Классы БЭМ-подобные: `.panel-btn`, `.glass-card`, `.dg-table`
- Переменные тем задаются в `:root` (default = Obsidian) и в `[data-theme="..."]` блоках

**PHP (DataGrid):**
- Статический метод `DataGrid::render(array $config): string`
- Конфиг: `columns` (key, label, sortable, width, format), `rows`, `actions`, `pagination`, `filters`, `empty`
- Не выполняет запросы к БД — принимает готовые данные
- Вывод экранируется через `TemplateEngine::e()`

**JS:**
- Vanilla, без зависимостей, `addEventListener`, модули через отдельные файлы
- Настройки вида: `data-*` атрибуты на `<html>` + localStorage
- Тема: `data-theme` на `<html>` + сохранение в БД (user_preferences)

## Testing Strategy

- Ручная проверка после КАЖДОГО шага (решение 18-B): зайти в админку, пройтись по всем разделам
- Проверка переключателя тем и настроек вида
- Проверка, что все CRUD работает (создание/редактирование/удаление)
- Проверка, что лендинг HexaVeil и блог НЕ изменились визуально
- Каждый шаг завершается коммитом (откат — через git)

## Boundaries

### Always do
- Коммит после каждого шага
- Проверка каждого экрана в браузере после изменений
- Использовать только CSS-переменные для цветов
- Сохранять имена полей форм и маршруты без изменений

### Ask first
- Изменение структуры `core/routes.php`
- Изменение контроллеров (логики)
- Любые изменения в HexaVeil или блоге
- Добавление новых зависимостей/библиотек
- Изменения в БД (кроме одной ALTER для user_preferences)

### Never do
- Не менять маршруты и имена полей форм
- Не ломать работу HexaVeil и блога
- Не коммитить секреты/токены
- Не удалять рабочий функционал «по пути»

## Success Criteria

- [ ] Админка выглядит как remnawave-admin: тёмный сайдбар, glass-карточки, mesh-фон, те же шрифты
- [ ] Переключаются все 6 тем + светлый режим, выбор сохраняется в БД
- [ ] Настройки вида (плотность/радиус/шрифт/анимации) работают
- [ ] Все 7 списков админки рендерятся через `DataGrid`
- [ ] Командная палитра Ctrl+K открывается и ищет по разделам
- [ ] Сайдбар сворачивается в узкий режим
- [ ] Все CRUD-операции работают 1:1
- [ ] HexaVeil и блог визуально не изменились
- [ ] Нет ни одного файла-монстра (>500 строк CSS/PHP/JS) — всё модульно
